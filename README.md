# Mars Rover Camera Usage Visualization

This project is a D3.js interactive bar chart that shows how often each Mars rover camera was used, based on data from NASA's Mars Photos API.

## What It Does

- Fetches rover manifest data from the NASA API
- Calculates how many sols (Martian days) each camera was used
- Groups cameras by category: Engineering, Science, or Entry/Descent/Landing
- Visualizes the data in an interactive bar chart using D3.js

## Background

This project is based on a final project from *JavaScript Crash Course* by Nick Morgan, which used the GitHub Search API. I adapted the concept using the NASA Mars Photos API.

## Development Notes

This repo was a standalone test version of the visualization. I later integrated it into a larger project.
